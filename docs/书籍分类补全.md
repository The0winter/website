# 书籍分类补全

分类资料与正文来源独立。查找顺序为起点等出版平台、当前实际绑定的采集站、其他核实来源；同名作品同时核对作者，改名只使用单本已核实的别名。无法确定主分类时保留未分类，不根据书名猜测。

拾页窗口的新书采集、书库续更和 CLI 的 probe/download 已接入起点公开资料查询。成功结果缓存 30 天，无匹配缓存 7 天；验证页面或网络失败触发 6 小时冷却，期间使用采集站分类。查询只读取公开搜索页和作品资料，不请求付费正文、不自动登录或弹窗。当前环境直连起点返回 HTTP 202 验证页面，因此本次出版平台例外项使用检索服务取得的页面内容核实；这不代表直连解析已实网通过。普通编程调用 `acquire` 可用 `publisherCategories: true` 启用相同查询。

`metadata.category` 支持唯一 CSS 容器、属性、正则和多个候选规则。仅归一化明确标签；多个有效规则得出不同主分类时记为冲突，不自动选择。系统流、重生、穿越、数字分类 ID、其他等不会作为主分类。简繁体标签归一化；二级分类、原始标签、来源地址、响应哈希及核对时间保存在 `categoryEvidence`。分类对照见 `tools/novel-crawler/categories.mjs`，包括诸天无限、轻小说、体育、军事等类别。

分类提取属于书籍资料更新，不改变目录和正文规则，也不改变既有提取指纹。新增此字段不修改来源 variant，旧任务、阅读版及续更绑定继续有效。没有取得有效分类时，不向已有导出添加空分类或仅有检测状态的资料，避免无意义重写阅读版。

## 覆盖保护与核对记录

- 既有无来源标注的分类视为人工选择；空值或新的采集站标签不会覆盖它。出版平台证据可提升采集站分类，明确核对登记优先。
- `.novel-crawler/book-categories.json` 按书名、作者和已核对来源地址保存登记，不把书籍身份硬编码进程序。
- 书库上传只补线上缺少的分类；已有分类即使与本地不同也保留。需要纠正已有线上分类时，使用明确的资料核对流程。
- `category-refresh.mjs` 的 `collectBookCategories` 只生成计划及证据，不修改本地书籍或网站。它接收线上书籍清单与 `planLibrary` 得出的实际绑定，不把旧导入地址误当成当前正文来源。
- `category-update.mjs` 的 `updateLocalBookCategory` 使用采集器同一套书籍锁和任务锁；核对原文件哈希后同时更新下载文件、原始导出指纹、阅读版和续更绑定。已被有效续更绑定替代的旧检查点保留原样。每本书有压缩恢复备份与操作日志，进程中断可续行，遇到外部修改则停止。逐本验证除分类及分类依据外的所有书籍内容保持一致。

首页移动端、桌面端和排行榜同步提供完整主分类入口，沿用各自的网格、换行和横向滚动交互。
