# 移动端阅读纸张与排版

## 参考与判断

依据用户提供的起点阅读截图调整。起点移动站未能访问，无法验证其资源或源码；下述纹理实现是本项目的方案，不代表起点的内部实现。截图经过缩放，字号和间距只能按比例估算，不能从图片推断精确 CSS 数值或设备字体。

- 截图约每行 16 个汉字，左右各留接近一个字的空白。字体接近常规字重的中文黑体。按 390 CSS 像素宽度估算，22px 左右的字号已经接近参考，舒适度差异主要来自间距与底色，而非一味放大字号。
- 段内行高约为字号的 1.45～1.55 倍；段落之间另有约 0.7em 空白，加上两个字的首行缩进，长段和对话的层次更明确。
- 纸张由暖色底、缓慢变化的明暗、细小纤维和颗粒组成。各层保持低对比，避免粗糙斑点与文字竞争。

## 本次实现

适用于小于 1024px 的阅读区域：

| 项目 | 调整 |
| --- | --- |
| 羊皮纸底色 | `#e7d2ae` → `#ddc7a2`，叠加纹理后略深 |
| 正文颜色 | `#382b19`，深暖棕 |
| 默认字号 | 保持 22px；不覆盖已保存字号 |
| 默认行高 | 1.6 → 1.5；设置中保留原有档位并增加 1.5 |
| 字距 | 0.035em → 0.015em，保留中文两端对齐及 2em 首行缩进 |
| 标准段距 | 固定 16px → 0.72em；22px 正文约 15.84px，随大字号一起增长 |
| 章节标题 | 1.4em/700 → 1.2em/600，减少标题挤占正文 |
| 字体 | 使用设备上的苹方、思源黑体/Noto Sans 或微软雅黑，并保留宋体、楷体选择 |

纹理由 CSS 内嵌 SVG 中三个尺度的静态噪声组成，使用灰度转换后的透明度，避免彩色噪点。无需下载几十张图片，也无需持续运行 Canvas 或动画滤镜。

左右/上下翻页对同一张 768×1024 的无缝纹理使用确定的取样偏移，每页细微不同。预览页使用目标页偏移；取消翻页、反向翻页和刷新恢复保持对应纹理。阅读进度额外保存 `paperPage`，用于详情页“开始/继续阅读”的加载纸张衔接；旧进度记录仍可读取。连续滚屏保持固定纸面，不随进度跳动纹理。

夜间模式及其他纯色主题保留原外观。桌面维持原有底色、纸张和排版尺寸。用户已保存的字号、字体、行高、段距档位继续生效。

## 验证范围

新增 `reader-paper-finish.spec.ts` 覆盖 320/390/430px 的纹理变化、回翻、刷新与详情页续读、较大字号下的段距、自定义设置及夜间/桌面默认行为。复用既有纸张衔接、分页连续性、连续滚屏、目录、阅读历史和手势测试，验证正文边缘无裁切、跨章不漏页、加载层退场无底色闪变。浏览器对合成图像可能有单通道 1/255 的舍入差异，像素比较只允许这一容差。

`reader-interactions.spec.ts` 中 3 条旧的 `warm … without a loading flash` 测试要求完全不渲染加载页，与目前统一的纸张加载过渡不符。在修改前的 `e4107ee` 源码上复测，3 条同样失败于 `entryFrames` 非空；本次未改变这一既有行为。现有 `reader-paper.spec.ts` 与 `reader-catalog-handoff.spec.ts` 用实际像素和遮罩退场检查当前加载过渡。
