# 书籍里程碑

详情页左侧轮播收藏、浏览的最高已达成等级，点击打开按北京时间归日的里程碑时间线。桌面入口位于评分下方。未达成时显示下一目标与空状态，不生成虚假记录；没有徽章墙。

- 收藏：300、500、1000、3000、5000、1万、2万、3万、5万、10万、20万、30万、50万，之后按每个数量级的 1、2、5 递增。
- 浏览：1万、5万、10万、20万、50万，之后按每个数量级的 1、2、5 递增。
- 收藏按真实书架人数计算，重复收藏不增加。浏览沿用章节阅读去重计数，访问详情页不会增加浏览。
- 达标记录保存在书籍的 `milestoneHistory` 中，与计数修改使用同一事务；收藏写入锁定书籍，避免并发重复记录。取消收藏仍保留已达成里程碑。
- 旧书首次修改统计前，以原始计数补齐历史成就，日期为 null，界面标为“历史达成”；新跨越的阈值记录实际达标时间。只读查询可展示旧书的可证实历史阈值，不伪造日期，也不写库。
- `/api/books/:bookId/milestones` 遵循现有作品访问权限，返回当前计数、历史记录和下一目标，响应不缓存。

部署新增 `Bookmark` 的 `{bookId: 1}` 普通索引即可，无需删除或重建现有数据。字段都是兼容性新增，旧版本可读；回滚期间旧代码不会记录新达标时间，重新启用后只能将缺少的记录认定为历史达成。

验证：`server/tests/book-milestones.test.js` 检查阈值、并发收藏、阅读去重、取消再收藏、历史回填、权限和事务回滚；`web-next/tests/book-milestones.spec.ts` 检查六种屏宽、滚动入口、日期分组、返回/前进、空状态、错误重试与目录共存。
