# 创作空间与作品数据

首次创建只填写书名、简介和可选封面，点击「创建」保存为私密作品，并返回「我的作品」第一页。手机端使用带右上角关闭按钮的卡片，桌面端使用居中的简洁表单；关闭时保护尚未提交的内容。

作品列表中的「创作」进入原有文稿上传、码字、预览和发布流程。手机端作品卡片放大并居中展示封面；「创作」左侧齿轮提供转为私密、删除等管理操作。已有文稿仍保留修订号及幂等保存，创建不要求章节、不自动公开。

## 作品管理

- `GET /api/writer/works` 仅返回登录作者自己的作品，将未发表的 Manuscript 与 Book 在数据库内合并、排序、分页。仅保存的文稿直接出现在“我的作品”，带“私密”标签；发表后同一列表显示正式作品，不保留重复条目。
- 私密文稿继续使用已有修订号、幂等保存和发布事务；无须迁移文稿数据。
- Book 的 `visibility` 为 `public` 或 `private`，旧记录缺省为公开。作者可转为私密、删除或在继续创作中重新公开。
- 私密作品从公开列表、搜索、排行、作者作品及 sitemap 中排除；目录、章节、评论和作品详情的所有入口先验证所有权或管理员身份。书架与历史记录将私密作品显示为不可用，不返回其章节标题。
- 章节标题可以留空，发表时自动使用“第 N 章”，前端不提示补填章名。

## 浏览统计

`GET /api/writer/statistics?period=day|week|month&end=YYYY-MM-DD` 只统计当前作者未删除的作品，含私密作品的既有浏览量。日、周、月按北京时间自然日、周一和每月一日分组，支持向前与向后分页，图表可以横向滚动并查看表格。

总浏览量沿用 Book 的历史累计值。趋势复用已有 ReadDaily 数据，今后的日汇总不再自动过期。早于当前最早记录的区间显示为未记录，不能凭总量还原已经过期的每日数据。上线时移除现存 ReadDaily 的 `expiresAt` 值，保留已有汇总。

ChapterRead 在原阅读去重事务内累加，保持同一读者当天阅读同一章计一次的口径。单章最高浏览量从此功能上线开始记录，不推算过去未记录的次数。新集合建立 `{bookId:1, views:-1}` 索引。

## 部署与回滚

旧后端不理解 `visibility`，不能直接回滚。部署同时准备两份兼容回滚目录，保留其原有前端构建，携带本次后端权限与统计改动，并分别验证后再写入验收标记。保留线上既有 R2 正文适配，不以仓库旧正文实现覆盖。版本清理仍使用现有 retention 服务。
