# 目录按位置加载与批次测试

2026-09-11。本次延续紧凑正序目录和定位后显示的交互，改动加载方式。

## 实现

- 新增 `/api/books/:bookId/catalog`。按章节 ID 直接读取附近窗口，同时返回全书章数、窗口起点和当前章节的真实索引。利用现有书籍与章节号索引；软删除和不连续章节号不会造成错位。只返回 ID、标题和章节号，不读取正文。
- 详情页和阅读页使用同一份目录缓存，保留 SSR 首批预览。新打开目录先读取阅读位置附近，不依赖前面的目录到齐。
- 列表使用全书索引进行虚拟显示，空缺窗口按需读取；补齐其他位置不会挪动现有章节。用户滚动的请求优先，最多两个请求并行，后台最多占一个名额。
- 不固定为每批 200 条：长目录首次和用户跳转窗口最多 128 条；已知不超过 512 章的短目录在正常网络下可一次读取；正常网络后台最多 2048 条，3G、低带宽等情况缩为 512 条。后台填充仅在目录打开时进行，关闭或页面不可见时停止；省流量、2G 模式按需读取。
- 超过 20,000 章的书按需读取，不自动下载全目录。每本最多缓存 20,000 条元数据，丢弃远处数据后仍可重新读取；共享缓存索引保留最近三本书。缓存有效期 60 秒，并根据 `writeVersion` 校验；版本变化后清空旧索引重新定位，避免混合新旧章节。
- 旧 `/chapters` 分页接口保留原来的上限和返回格式，供 SSR、站点地图和其他既有调用使用。

## 测试方法与结果

使用独立的临时 MongoDB 副本集、375 章和 10,000 章的合成书籍，Chrome 实际请求本地 API。比较 128、256、512、1024、2048 条窗口，目标在目录约 80% 处。网络由 Chrome 模拟：正常网络 80ms 延迟、1MiB/s；慢网 250ms 延迟、64KiB/s。窗口请求各取三次的中位数；补齐耗时为一次完整对比采样。缓存关闭，旧策略额外使用不重复的查询参数和 `cache: no-store`，防止浏览器验证缓存影响冷加载对比。

这些数据是合成场景中的 API 返回时间，不包含打开书籍页面、正文加载和界面绘制，也不是对用户实际网速的承诺。

### 万章目录首次目标窗口

| 请求条数 | 正常网络 | 慢网 | 返回数据 |
| --- | ---: | ---: | ---: |
| 128 | 112ms | 560ms | 17,735B |
| 256 | 140ms | 824ms | 35,399B |
| 512 | 168ms | 1,356ms | 70,727B |
| 1024 | 231ms | 2,432ms | 141,383B |
| 2048 | 372ms | 4,600ms | 282,695B |

旧的 200 条、后三路并行策略，必须从开头连续加载到目标，冷加载正常网络约 3,643ms、慢网约 35,693ms。直接请求目标窗口消除了这一依赖。

375 章的书，正常网络一次返回全目录约 154ms，附近 128 条约 123ms；慢网分别约 1,057ms 和 558ms。因此小目录在较好网络下合并读取，而弱网优先保证当前区域可用。

### 万章目录后台补齐

| 每批上限 | 请求数 | 正常网络 | 慢网 |
| --- | ---: | ---: | ---: |
| 512 | 20 | 3,356ms | 26,838ms |
| 1024 | 10 | 2,303ms | 23,871ms |
| 2048 | 5 | 1,837ms | 22,564ms |

2048 条在本次批次范围内补齐最快。弱网仍采用 512 条，降低单个后台响应的占用时间；可见区域请求保留独立名额。新接口补齐全目录约传输 1.38MB 元数据，旧接口约 2.64MB，减少约 48%。

复现：在项目根目录，用项目指定 Node 22 执行 `node tools/benchmark-catalog.mjs` 和 `node tools/benchmark-catalog.mjs --bulk`。结果写入 `artifacts/`，临时测试数据库关闭后销毁，不使用生产库。

## 回归范围

- 目录接口的范围限制、删除过滤、章节号空缺、书籍下架、正文不泄露、版本冲突。
- 阻塞前部目录时，手机与桌面的详情页、阅读页仍能直接显示第 1000 章；逐帧检查首次显示位置不跳动。
- 同时延迟后台请求并跳转到未加载位置，验证用户请求优先；跨详情和阅读页复用窗口，不重复定位请求。
- 缓存容量、版本变化、失效章节、失败重试、鼠标和触摸拖动、键盘目录导航。
- 三种阅读模式的目录开关、章节选择、返回、加载遮罩衔接，以及已有详情页统计。

另行检查无 JavaScript 阅读时，发现现有书籍进入遮罩使正文不可见；上线前的旧版本 `67f8c33` 公网也能复现。本次未改动该遮罩或无脚本路径，不将这一独立问题记录为已通过。
