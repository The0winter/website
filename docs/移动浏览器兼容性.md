# 移动浏览器兼容性

本轮范围为 Safari、UC、Edge、QQ 和此前访问份额榜中的 Android 类别。Android 是统计分类，不代表某一款当前产品，也不代表所有 Android 浏览器；不能据此声称所有国产手机浏览器均已真机验证。

后续追加夸克 Android/iOS 分享能力检查、夸克 UA 下的阅读/全屏降级检查，以及六类浏览器配置下的论坛回归。UA 只用于选择能力与提示路径，版本标记不代表已安装或实测对应手机版本。

## 页面行为

- 分享继续优先使用 Web Share；UC、QQ 仅在实际提供接口时使用其桥接，失败仍可复制或手动选择链接。分享详情见 [书籍分享兼容性](书籍分享兼容性.md)。Android 默认浏览器带有 Safari 字样的 UA 不再收到苹果浏览器指引。
- 分享链接输入框使用 16px 字号，减少 iPhone 聚焦小字号输入框引起的自动放大；不禁止用户缩放。
- 全屏同时识别标准 API 和实际存在的 WebKit 前缀 API。前缀调用可能返回 void，必须等到全屏状态变化后才重新分页。错误事件或调用无响应会恢复操作并允许重试，不把接口调用成功当作进入全屏成功。
- 没有全屏 API 时保留正常阅读和设置；网页无法强行隐藏浏览器自身工具栏。
- 现代浏览器继续使用动态视口高度 dvh；不支持时使用 innerHeight 并跟随窗口大小和方向变化。没有 ResizeObserver 时仍在视口变化后重新分页。正文限制浏览器自动文字膨胀，保留阅读字号设置和用户缩放。
- 详情页、阅读入口、翻页和全屏遮罩的 JS 动画缺失、抛错、缺少 finished Promise 或停止完成通知时，仍会结束过渡并释放遮罩。减少动态效果偏好继续生效。
- 目录和分享面板补充 vh 尺寸回退；阅读设置与段评面板共用阅读视口高度。桌面布局保持独立。

## 验证边界

`web-next/playwright.compat.config.ts` 覆盖实际 WebKit 和 Edge 引擎，以及 Chromium 上的 UC、QQ、Android UA/接口能力配置。测试涵盖详情进入阅读、进度恢复、横竖屏、三种阅读模式、复制失败、动画降级、前缀全屏和全屏无响应。

UA 配置不等于安装了对应手机浏览器。没有连接真实 iPhone、Android 手机，本轮不能验证系统分享面板、手机浏览器工具栏、系统返回手势及所有厂商内核版本。接口桥接和前缀全屏采用模拟检查；最终保留实际能力检测和失败回退。

项目使用的 Next.js 默认支持底线为 Chrome/Edge 111+、Safari 16.4+、Firefox 111+（见安装包 `web-next/node_modules/next/dist/docs/03-architecture/supported-browsers.md`）。针对缺失个别 API 的回退不等于支持 Android 4.x 系统浏览器或任意低版本 JS/CSS 内核。

测试通过项目根目录的 `npm run test:browser -- --config web-next/playwright.compat.config.ts` 执行，Windows 按 AGENTS.md 先预加载隐藏窗口工具。另回归分享、标准全屏、全屏返回和连续滚动用例。

依据：[Web Animations 规范](https://www.w3.org/TR/web-animations-1/)、[WebKit 动态视口单位说明](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)。

## 论坛优化与故障复现

- 首页、书架与论坛之间的切换使用相同动画降级封装。原先动画 API 缺失/抛错可中断导航并留下遮罩；现在完成位置独立于动画效果设置，缺少完成 Promise 或停滞也可释放遮罩。
- 初次进入只加载当前分类，热榜/关注在选择时加载，已访问分类保留 60 秒缓存。论坛写入仍刷新访问过的分类，登录状态变化清空缓存并忽略旧帐号迟到的请求。
- 移动/桌面共用一份分类列表，桌面仍采用双栏布局；横向拖动直接更新轨道偏移，不在每个 touchmove 中重新渲染整页，纵向滑动不触发拖动状态渲染。头像延迟加载。
- 网络失败显示重试入口，后台更新失败保留已有列表。
- 回答链接 `/forum/回答ID?fromQuestion=问题ID` 原先被入口校验及标题元数据当成帖子 ID，导致直接访问有效回答返回 404。入口改为校验该问题下的对应回答，元数据在可读取查询参数的服务端 page 中读取父问题。

验证入口：`npm run test:browser -- --config web-next/playwright.forum.config.ts`。列表使用合成数据验证请求数量、失败重试、慢请求切换、窄屏/桌面布局；回答路由使用本地隔离数据库。Chromium 使用 4 倍 CPU 限速和原生触控调度检查有内容的列表，既有论坛手势测试另覆盖 8 倍限速。WebKit 不支持此 CDP 限速测试，不能把其跳过项当作通过。新增检查仍不替代夸克等手机真机验收。
