# 小说导入与作者资料

在项目根目录运行（需本机 Node 22 和可连接 VPS 的 SSH 密钥）。数据库密码和导入密钥始终留在 VPS。

仅检查本地文件，不连接服务器：

```powershell
node infra/import-vps.mjs "downloads/1984：从破产川菜馆开始.json" --validate-only
```

对服务器预检查，不写入书籍和作者：

```powershell
node infra/import-vps.mjs "downloads/1984：从破产川菜馆开始.json"
```

正式上传（先完整预检查，再每批 20 章写入）：

```powershell
node infra/import-vps.mjs "downloads/1984：从破产川菜馆开始.json" --apply
```

默认 SSH 目标 ubuntu@51.79.242.0、密钥 ~/.ssh/ovh_website_ed25519；可用 --host=用户名@主机、--identity=密钥路径覆盖。只传输选中的 JSON，服务器使用私有临时文件，结束自动清理。单文件上限 512 MiB。

格式保留 title、author、sourceUrl、chapters；章节包含 title、content、chapter_number（兼容 chapterNumber）、可选 link/sourceUrl。章号必须是正整数且整本不重复；不猜测缺失章号，不自动截断超过 60000 字符的正文。读取前校验整本书，按明确章号排序。

可选元数据：description、category、cover_image（HTTP(S) 地址）、status（连载/完结）、authorSourceUrl（作者公开来源页）。没有这些字段时保留既有值；提供的简介、封面、分类、状态会更新。封面保存 URL，不自动下载图片。

作者保存在独立 authors 集合，通过 Book.author_profile_id 关联；没有密码、邮箱或登录权限，不修改 Book.author_id 的账号归属。同一 authorSourceUrl 复用作者资料；未提供作者来源时按书籍来源及作者名区分，不仅按同名笔名合并。若要让同一作者的多本书归入同一个作者页面，首次导入前应为它们填写相同的 authorSourceUrl。已关联作品更换作者来源会明确报冲突，不能悄悄转移。

书籍通过 sourceUrl 识别，不按书名覆盖。重复运行核对已有章节，完全相同则跳过；内容/来源冲突会停止，已下架书章不会复活。每批事务包含作者关联、元数据和章节，失败整批回滚；整本书并非一次事务，中断前已成功的批次保留，重跑即可复核续传。完整预检查后仍可能发生并发修改，因此不能保证整本书原子导入。

本地旧入口 upload_to_vps.js 仍支持通过 IMPORT_API_URL（回环地址）与 IMPORT_SECRET 使用，支持 --validate-only；普通 VPS 上传优先使用上面的新入口。run_update.js、旧修库脚本和旧库 data 均不参与此流程。
