# 拾页网站监控（第一版）

这是按需运行的本地只读工具。打开窗口立即检测，运行时定时刷新，可手动刷新或暂停。关闭窗口后停止本地调度、取消请求并关闭 SSH 和独立浏览器进程。没有常驻服务、开机启动项、系统计划任务或监控数据库。

## 启动

- 桌面快捷方式：**拾页网站监控**。
- 项目命令：`npm run monitor`。
- 重新创建快捷方式：`npm run monitor:shortcut`。
- 程序源码：`tools/site-monitor/`。

复用项目现有 Node / Puppeteer 和已安装的 Chrome 或 Edge，以独立应用窗口运行，不使用日常浏览器的个人资料。启动脚本隐藏控制台；手动打开快捷方式时才显示程序。Bootstrap 5.3.8 样式和许可证已保存在项目内，不依赖在线 CDN。桌面图标由项目内的 SVG 生成。

首次连接默认复用项目当前 SSH 主机和密钥路径。服务端数据库、R2 和监控凭据从现有 `/etc/test1/api.env` 读取，不打印、不复制到本地。主机指纹必须已在 OpenSSH 的 known_hosts 中验证；程序不自动接受新指纹。更换电脑时先独立核对 SSH 连接。

## 页面与数据口径

| 页面 | 第一版能力 |
| --- | --- |
| 总览 | 连接状态、CPU、可用内存、Atlas 容量、磁盘余量、本次曲线 |
| 服务器 | CPU 差值、内存、磁盘/inode、网络速率、固定 systemd 服务状态、重启次数、内存限制、部署版本、最近备份清单 |
| Atlas | 实际 ping、业务库数据与索引、记录与集合数；支持时通过 `atlasSize` 读取全体数据库的逻辑大小 |
| R2 | 两个桶的可访问性、响应时间；手动启动有上限的容量与对象数量盘点，并区分正文/草稿/备份/封面 |
| 报告与清理 | 保存 JSON / 曲线 CSV、下载副本、清理预览与执行 |
| 连接设置 | SSH 主机、密钥路径、HTTPS 网站地址、手动配置的 Atlas 套餐容量上限 |

服务器每 15 秒、Atlas 与网站 HTTPS 每 60 秒、R2 桶状态每 5 分钟刷新；频率从上一次完成后计算，慢请求不会叠加。同模块手动刷新与自动刷新合并。暂停后仍可以手动刷新；已开始的查询会完成。请求失败保留旧值并显示失败；超过两倍正常采样间隔标记过期。CPU 和网络速率至少需要两次有效样本；计数器重置时重新采样，不显示负值。

网站 HTTPS 指标仅验证首页请求状态与响应时间，不代表所有业务流程都正常。服务器的 API 连接状态只是现有监控接口报告，Atlas ping 则另行执行真实往返。

当前 SSH 和服务器业务凭据本身可能有高于只读的权限；本程序只执行源码内固定的读取命令，不提供自定义远程命令，也不新建或改变服务器账号。数据库连接关闭自动创建集合和索引；不向业务数据库写入任何监控记录。目录不存放用户列表、正文或草稿。

## 第一版明确的指标边界

- 当前没有 Atlas 管理 API 凭据，连接额度、操作量、七天传输量标记“未接入”。不把服务器网络量当成 Atlas 传输量。
- 当前没有 Cloudflare Analytics 权限，R2 历史请求量、免费额度消耗和账单标记“未接入”。不把对象列表盘点当作官方计费统计。
- R2 自动刷新只调用桶状态读取。手动盘点分批列举元数据，不下载正文，每批最多 10 页、每桶最多 200 页，每页最多 1,000 个对象；分页之间有间隔。失败、取消或达到上限时保留“部分统计”，不能当成全部容量。并发增删对象会影响盘点结果，列表不是事务快照。
- Atlas 套餐容量上限默认留空，按控制台的真实套餐填写（MiB）。使用全体数据库的逻辑大小判断边界；不能只用业务库，也不能用物理分配空间代替。
- 曲线只反映程序打开期间，每模块最多 1,440 个点，显示最近 180 点。超出内存窗口时移除最早点，关闭后清空。第一版不基于短时间采样预测触顶日期。
- JSON 保存完整本次状态、曲线及盘点摘要；CSV 保存曲线。第一版报告供下载或其他工具读取，尚无历史报告回放页。

## 本地存储与过期清理

状态目录固定为项目 `.runtime/site-monitor/`，不提交 Git。

| 文件 | 生命周期 |
| --- | --- |
| `config.json` | 连接参数与容量阈值，长期保留；不保存密码或云令牌 |
| 内存快照、曲线 | 不自动写文件，关闭即丢弃 |
| `reports/monitor-*.json`、`.csv` | 仅点击保存时生成；保留 30 天，目录总量预算 200 MiB，单份上限 16 MiB |
| `browser/session-<UUID>/` | 独立临时浏览器；正常退出后清理。崩溃残留需确认节点和浏览器 PID 均不再活动，过期后回收；启动前若残留已达 256 MiB，暂停启动并提示整理 |
| `last-launch.log`、`last-launch.error.log` | 启动时覆盖，不按每次启动新建；程序不连续写监控日志 |

清理接入统一 `tools/storage-maintenance.cjs`，复用路径校验、符号链接防护、Git 跟踪保护、`.storage-keep`、执行前重新盘点和指纹核对。

```powershell
npm run monitor:clean:plan  # 仅预览监控工具产生的文件
npm run monitor:clean       # 执行这一范围的清理
npm run storage:plan        # 全项目维护预览，也包含监控文件规则
```

自动清理仅在启动、运行每小时、保存前与退出时执行，不安装计划任务。30 天从本地文件修改时间计算。超过容量预算时优先淘汰最旧托管报告；保护文件导致没有空间时拒绝继续保存。需要长期保留的报告请下载副本到其他目录，外部副本不自动清理；也可以放置 `.storage-keep`，但受保护文件超出预算后需自行整理。

程序不会清理服务器文件、数据库、R2、小说、封面、业务备份或不认识的文件。用户自行在专用目录添加的文件也不猜测用途。

## 验证与维护

```powershell
npm run test:monitor
npm run test:storage
npm run test:browser -- site-monitor.spec.js
# 显式联网的只读验收，隐藏窗口；自动单元测试不会连接生产环境
node --require ./tools/test-env.cjs tools/site-monitor/tests/live-smoke.mjs --inventory
# Windows 正式快捷方式链路验收：使用默认项目目录、隐藏窗口，验证关闭后进程与缓存退出
node --require ./tools/test-env.cjs tools/site-monitor/tests/launcher-smoke.mjs
```

测试在 `.runtime/test-tmp/` 使用隔离工作目录；界面验收材料放 `.runtime/task-artifacts/site-monitor/`。本地程序修改不需要发布网站或重启线上服务。
