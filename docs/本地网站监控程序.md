# 拾页网站监控

桌面打开 **拾页网站监控**，即可查看网站运行情况和读者活动。已有快捷方式继续有效；关闭并重新打开即可使用更新后的程序。也可以执行 `npm run monitor`。

这是本机按需运行的只读工具，不安装后台服务或开机启动项。关闭窗口会取消请求、断开 SSH 并退出独立浏览器；网站和谷歌自己的访问记录仍然继续。

## 先看哪个页面

| 页面 | 回答的问题 |
| --- | --- |
| 运行概况 | 日活、周活、月活、新增访客及注册如何变化？有运行异常吗？ |
| 访客与内容 | 读者从哪里来、使用什么设备、喜欢读什么？ |
| 容量与服务 | 内存、磁盘、数据库还有多少空间？关键服务和备份是否正常？ |
| 正文与封面 | 云端小说与封面能否读取？需要时盘点对象容量。 |
| 报告与清理 | 保存当前结果、下载副本、清理本程序的过期文件。 |
| 连接设置 | 配置谷歌只读授权、数据库套餐容量和服务器连接。 |

容量采用类似磁盘的横条：已用达到 **80% 提醒，90% 标红**。颜色旁同时显示文字。没有确认容量上限、查询失败或旧数据过期时显示灰色状态，不当作正常，也不凭空预测还能撑几天。

运行概况左侧用三个圆展示人数：今日日活在上方大圆，周活和月活在下方左右两个小圆；各圆下方显示对应周期的新用户数。趋势图在右侧，窄窗口也保留左右布局。顶部删除网址、本机时钟、英文标识和说明，右上角仅显示当前数据最近成功读取时间，自动读取继续运行；读取时间使用本机时区，不随本机时钟每秒更新。容量只占紧凑横条；正常运行状态收在底部，访问抽查可展开。检测到实际异常或风险时，状态与原因自动移到最前面。尚未确认的状态在底部明确标注，不当作正常。

## 用户变化与活跃口径

- 日活（DAU）是今天截至读取时的去重活跃用户；周活（WAU）、月活（MAU）分别是包含今天的最近 7、30 天去重活跃用户。三者分别查询 GA4 `activeUsers`，不会把每日人数相加。今天尚未结束且谷歌处理有延迟，不能当作最终人数；下方不再重复展示“今天活跃”。
- 各圆内“新用户”是同一周期的 GA4 `newUsers`（新增访客），不是新增注册账号。新增注册来自网站数据库，单独标注。
- 用户变化的日趋势展示最近 14 天（前 13 个完整自然日，加今天累计），周/月趋势展示最近 8 个完整自然周、6 个完整自然月；周一开始。每周、每月直接按 `isoYearIsoWeek`、`yearMonth` 查询去重用户。日趋势末尾用空心点、虚线和“今日”坐标标识未结束的一天；悬停注明“今日累计，尚未结束”。今日点直接使用同一数据源、同一地区的日活圆及新用户值，不再次查询或累加。新增注册及第一方原始/建议过滤的日图同样补入当天累计；周/月趋势仍展示完整周期。
- “全部／中国／其他国家”同时筛选谷歌的三个活跃人数圆及趋势。按 GA4 访问发生地 `countryId` 筛选：中国为 `CN`，其他国家为已识别的非 `CN` 地区；未识别地区仅计入全部。跨地区访问的同一人可能同时在两组出现，因此不能把各国人数相加或用总人数减中国人数代替去重查询。各地区分别在服务端查询整个周期；地区查询失败显示未知，不拿全站人数代替。依据：[GA4 国家维度](https://developers.google.com/analytics/devguides/reporting/data/v1/api-schema#dimensions)、[维度过滤](https://developers.google.com/analytics/devguides/reporting/data/v1/rest/v1beta/FilterExpression)。
- 第一方观察和注册数据尚无国家信息，切换到这些图表时地区筛选禁用并说明原因。下方近 30 分钟活跃、今天浏览次数和注册数据始终是全站近况，有独立标注。
- 图中“访问用户”显示活跃用户与新增访客；“新增注册”显示现存账号的注册增长，同样可按日、周、月查看。访客使用谷歌资源时区，注册使用北京时间。已删除账号无法重建，缺少有效注册日期的记录单独标注。
- 鼠标悬停或触屏轻触显示日期和人数；在图上滚轮缩放，也可用加减按钮。缩放后可拖动时间滑杆，点击“显示全部”恢复。图表获得焦点后，左右键查看点、Home/End 到首尾、加减键缩放。自动刷新保留相同时间范围内的缩放位置。
- “查看趋势数字”提供当前可见区间的表格。隐私阈值等导致的缺口保留为未知，不补成 0；查询失败仍保留旧值并提示。

自动化访问识别已进入观察模式。图表数据源可选择谷歌访问用户、网站新增注册、第一方原始和建议过滤（观察）；下方展开观察条可看今天人数对照、会话分类和脱敏命中样本。GA4 原始口径保持不变，满 7 天标记可复核，不自动切换默认口径。规则与实际采集范围见 [疑似自动化访问识别方案](疑似自动化访问识别方案.md)。

## 网站运行的判断

- 通过公网依次 GET 首页、一本公开书的列表记录、目录和一章正文。首页检查 HTML；目录检查章节 ID；正文必须有非空内容。不执行网页脚本、不发送 GA 事件、不调用阅读次数上报接口。
- 这是代表性抽查，不保证所有书、所有用户操作都正常。HTTP 或内容验证失败标为访问异常；本机不能连接监控源时标为尚未确认。
- 读取服务器内存、磁盘、CPU 差值、文件数量余量及三个关键服务：网站入口、网页服务、业务服务。
- 同时检查单个服务的内存限制，避免服务器有余量、单个进程却即将达到限制而漏报。
- CPU 超过 90% 提醒；连续三次超过 90% 才称为持续繁忙。短暂高峰不会直接解释为崩溃。
- 自动备份记录超过 36 小时未成功更新时提醒。备份任务成功不等于完成恢复演练。
- 数据库容量必须用 `atlasSize` 返回的整个集群逻辑用量和实际套餐上限比较。集群指标取不到时不拿业务库大小代替；套餐上限默认不猜测。
- 未接入 Atlas 管理 API 的连接配额、操作量、传输配额仍明确标为未接入。R2 列表盘点不代表账单或硬容量上限。

总体状态是现有检测结果的摘要，不是故障预测或完整可用性保证；窗口关闭后没有本机检测或报警。

## 谷歌统计怎么连接

网站原有的 GA4 埋点继续使用，不需要换衡量 ID，也不需要重新部署网站。这里只读取 Google Analytics Data API。浏览器中已经登录 Google Analytics，并不等于此本地程序拥有 API 授权。

推荐为本程序提供专用的只读服务账号：

1. 在 Google Cloud 选择自己的项目并启用 **Google Analytics Data API**。
2. 创建专用于监控的服务账号，下载 JSON 密钥；这一步会创建持续使用的凭据，需要账号所有者完成或明确授权。
3. 在 Google Analytics 的“管理 → 媒体资源访问权限管理”中，将该 JSON 里的 `client_email` 添加为 **查看者**。无需编辑者或管理员权限。
4. 打开监控的“连接设置”，填写数字 **资源 ID**，选择 JSON 文件，点击“保存并检测谷歌连接”。资源 ID 不是 `G-` 开头的衡量 ID。

也可以填写已有授权文件的绝对路径，或使用带 `analytics.readonly` 权限的 Application Default Credentials（`authorized_user` JSON）。支持通过 `GOOGLE_APPLICATION_CREDENTIALS` 指定默认文件路径；不会扫描个人浏览器或借用浏览器 Cookie。

在界面选择文件后，授权保存到 `.runtime/site-monitor/google-credentials.json`。配置仅记录路径，密钥与令牌不会返回界面或进入导出报告；OAuth 令牌仅驻留内存。凭据不提交 Git，不能粘贴到聊天或共享报告中。需要撤销时从 Google Cloud/Google 账号撤销凭据，并在 GA4 中移除该查看者。

未配置、权限不足、API 未启用、网络失败和额度不足都有单独提示；未授权不显示假的零访客。已经获得的报表在后续请求失败时保留，并醒目标为旧数据。

参考：[Google Analytics Data API 接入](https://developers.google.com/analytics/devguides/reporting/data/v1/quickstart)、[批量报表](https://developers.google.com/analytics/devguides/reporting/data/v1/rest/v1beta/properties/batchRunReports)、[指标说明](https://developers.google.com/analytics/devguides/reporting/data/v1/api-schema)。

## 访问与业务数据的口径

| 指标 | 数据源与边界 |
| --- | --- |
| 活跃访客 | GA4 `activeUsers`，整段周期去重；不能将每日人数相加作为周期人数。 |
| 首次访问 | GA4 `newUsers`，不等于新增注册，也不简单视为活跃访客的子集。 |
| 页面浏览 | GA4 `screenPageViews`，一次访问可以浏览多个页面；不是所有按钮的点击数。 |
| 最近 30 分钟活跃 | GA4 实时报告，不称为当前在线人数。 |
| 访问来源、设备分布 | 按会话次数统计；设备比例按报表返回的次数汇总。 |
| 热门页面 | 按浏览量返回前 10 个“路径 + 标题”记录；页面改名可能分行。 |
| 注册总量及增长 | Atlas `users.created_at`，按现存账号计算；已删除的账号无法从当前库重建，日期无效的账号不计入增长并单独标注。 |
| 有效章节阅读 | `ReadDaily.views - baselineViews`，逐条不低于零，再汇总；剔除独立记录的展示基数。原有规则为同一身份同一天重复读同一章只计一次。 |
| 热门阅读作品 | 所选周期的有效章节阅读，排除已删除及私有作品。 |
| 收藏排行 | 当前真实 `Bookmark` 记录数，仅公开作品；不是书籍展示热度，不受所选日期范围影响。 |

“访客与内容”的范围可选 7、30、90 个完整自然日，截至昨天。运行概况的日/周/月趋势采用上方独立范围，不受内容页的范围影响。今天同时显示在日活圆和日趋势末尾，日图明确标注尚未结束；周/月图保留完整周期。谷歌使用报表返回的资源时区；网站注册与阅读按北京时间，两者分别标明日期和来源。

GA4 近期报表可能继续更新；收到隐私阈值、抽样或其他行合并提示时会显示，受限制的缺失日不补成零。无访问记录但查询成功的普通报表可以显示零。历史上未采集的点击行为不能补回。

业务查询只返回聚合数字、公开书名和书籍 ID，不读取用户名、邮箱、正文或个人阅读列表，不写业务数据库、不自动建索引；查询有时间限制。

## 刷新、报告与容量盘点

服务器每 15 秒、数据库与公网抽查每 60 秒、R2 可访问性每 5 分钟刷新；谷歌历史报表和业务统计每 15 分钟刷新，谷歌实时报告每 60 秒刷新。按上次请求完成时间调度，同模块请求合并，失败不清空旧值。顶部仅显示当前图表数据最近成功读取时间，各来源的错误和旧数据另行提示；不再显示暂停和立即检测按钮。

“换日”和“读取刷新”不同：打开监控立即读取，谷歌日活及日趋势随后约每 15 分钟读取一次；今天按谷歌资源返回的时区划分（当前已核验为 `Asia/Shanghai`，北京时间 00:00 换日）。按电脑当前 `Europe/Berlin` 时区，北京零点对应当地夏令时 18:00、冬令时 17:00，进入下一个北京时间日期。右上角读取时间使用本机时区，不能把它当成统计换日时区。跨过换日边界后，下次成功读取会展示新一天，失败则明确保留旧数据。

切换内容统计范围会取消相关旧请求，清空旧周期结果后读取新周期，不混用不同日期范围。谷歌每轮历史统计使用两次批量查询（5 张内容/汇总报表及 4 张活跃/趋势报表），每批不超过官方限制的 5 张；不下载事件明细。日/周/月视图使用已取得的数据切换，不额外发请求。注册查询只聚合近 400 天日期计数，以覆盖完整 12 个月；仍受只读权限和查询时间限制。

本次服务器运行曲线驻留内存，每模块最多 1,440 点；关闭后清空。访客、注册和阅读趋势来自源端已有历史，无需电脑一直开启。JSON 导出当前汇总及运行曲线，CSV 导出运行曲线。报告尚无回放页。

R2 自动检查仅访问桶状态。手动盘点每批最多 10 页、每桶最多 200 页，每页最多 1,000 个对象；失败、取消或达到预算时保留“部分容量”。不下载正文，列表也不是事务快照。

## 第一方观察采集

网站部署新增 `/traffic-observer.js` 与同源、CSRF 保护的 `/api/traffic/observe`。匿名身份使用服务端签名的 HttpOnly Cookie；页面和渲染后的章节切换上报打开事件，前台每 10 秒更新一次累积可见时长和交互计数。预取、静态资源、仅有查询参数变化及未执行脚本的请求不计入页面打开。失败后网站仍正常使用，上报队列最多 64 项、请求最多等待 5 秒。

30 分钟无活动重开会话，持续打开的会话最多 24 小时。服务端以接收时间校验时长上限，幂等处理页面 ID，最多保留每会话 120 页及 400 个打开时间；已截断样本标为 bounded。不会采集输入内容、完整 URL、邮箱、账号 ID、原始 IP 或完整 User-Agent，只留自动化声明布尔值。未知或缺失交互不算确认无交互；评分从不用于封禁。

MongoDB 的 `traffic_observation_sessions` 保存有界证据，TTL 30 天；`traffic_observation_summaries` 保存匿名去重标记与会话评分，长期用于重建周期去重和首次保留访问；`traffic_observation_meta` 保存观察起点和规则版本。显式部署步骤只给新集合增加索引，不在请求中自动建索引，也不迁移已有业务集合。可以设置 API 的 `TRAFFIC_ANALYTICS=off` 停止新采集；默认生产为 observe，非生产为 off。当前实现只启用 MongoDB 后端。

本地监控每 5 分钟通过只读聚合获取第一方对照，单个查询限时 5 秒、最多 10,000 个匿名访客；超过预算报不可用，不展示部分人数。它不接收身份标识或逐页记录。采集开始日及更早的完整周期均显示未知，日活圆显示今日已采集量，周/月活含今天；一个用户有任意保留会话仍计入保留人数，新增按首次原始/首次保留访问分别计算。两套第一方指标是已采集页面打开的匿名去重人数，与 GA4 活跃定义不等价。
