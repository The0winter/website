# 本地容量与清理

适用本地 Git 项目，默认不在 CI 或没有 `.git` 的发布目录执行。与服务器 `/srv/test1/releases` 的版本保留独立，不修改线上数据库、R2 或服务器配置。

## 入口

```powershell
npm run storage:plan     # 只预览，不删除
npm run storage:clean    # 重新检查当前状态后执行
npm run test:storage     # 隔离目录中的保护与淘汰测试
```

工具为 `tools/storage-maintenance.cjs`，阈值集中在 `POLICY`。没有任意路径或通配删除参数。`--initial` 只用于首次处理已审查的历史残留：仍保护当前构建、活动目录、配置、Git 文件和保留标记，但不保留旧验证构建的两份额度，并允许释放旧 npm/浏览器 HTTP 缓存。

根目录 `dev`、`build`、`start`、`test`、`test:crawler`、`test:browser`、`dev:isolated` 通过 `tools/local-run.cjs` 登记活动保护，并在开始/结束时安排隐藏后台维护。启动命令不等待全量扫描。`tools/test-env.cjs` 也保护直接运行的测试。采集 CLI、桌面启动及采集任务结束时会安排维护；使用正式缓存的 HTTP 客户端持有独立保护。

一次完全空闲的自动检查完成后，12 小时内不重复扫描。活动任务只保护对应类别，下次入口再尝试。后台助手检查完即退出，没有常驻进程或系统计划任务，不弹出窗口。新任务申请文件时，扫描在检查点让出维护锁；正在执行的单个目录删除完成后再让出。可为一次排查设置 `LOCAL_STORAGE_MAINTENANCE=off`；它关闭自动维护及活动登记，期间不要另开手动清理。

## 已落实的规则

| 类型 | 规则 |
|---|---|
| 构建目录 | 保护配置中的默认输出、当前 NEXT_DIST_DIR、活动构建；额外保留最新两份，其余闲置超过 48 小时淘汰。配置无法识别时全部保留。 |
| 隔离安装环境 | 保护 clean-room-report.json 引用的环境；另保留最近一份未满 7 天的失败环境。其余有完成标记的环境闲置超过 24 小时可清；无标记的历史环境须超过 7 天。报告损坏时全部保留。 |
| 测试临时数据 | 仅处理明确的 test1-mongo-*、test1-sqlite-*、mongo-mem-*、novel-browser-*；闲置超过 24 小时且无活动测试才清理。其余 test-tmp 子目录不猜测用途。 |
| npm / 旧浏览器 HTTP 缓存 | 无相关进程使用，闲置超过 7 天或超过 1 GiB 时释放。浏览器只涉及 browser_data/Default/Cache，不涉及 Cookies、Local Storage、会话或新采集浏览器目录。 |
| 采集网页缓存 | 仅处理正式 .novel-crawler/cache 中完整的哈希 .json/.bin 对；淘汰超过 7 天的无引用内容，或按最旧顺序降至 1 GiB。24 小时内刚写入的内容受保护。 |
| 调试截图/日志 | 在 artifacts、web-next/artifacts、.runtime/task-artifacts 中，仅选择名称含 initial、baseline、debug、pending、loading、before、after、strip-数字的 PNG/LOG。14 天淘汰，或在超过 500 MiB 时淘汰至少一天前的旧调试材料。 |

带 final、public、live、verified、accepted、cover、source、original 标记的验收/素材路径不进入截图清理。任意候选目录或其祖先放置 `.storage-keep` 可保留整棵子树。Git 跟踪文件、环境配置、符号链接及包含这些内容的目录自动跳过。

预算只约束**可再生成的无用内容**。原始网页若被书籍来源、逐章检查点、阅读版或续更记录中的哈希引用，会保留。损坏的证据元数据会让整个网页缓存类别跳过。受保护内容本身超过 1 GiB 时报告超限，不为满足配额删除证据。维护触发时才执行预算，活动任务和短期保护期内可暂时超限。

## 明确保留

downloads、Cover、backups、.novel-crawler/jobs、continuations、来源绑定、阅读版映射、整本中间文件、登录状态、环境文件及不明用途的任务快照均不是删除类别。采集前快照是恢复资料，不依靠目录日期判定它无用。今后对快照去重或减少 partial.json，必须先有独立恢复与引用验证，不能与缓存淘汰混用。

## 安全与验收

维护和活动登记共用互斥锁，已登记的活动任务受保护。工具还检查系统进程，以保护旧入口。进程读取失败或不明活动登记会停止清理。

执行在锁内重新生成白名单，对比大小、文件数、修改时间、文件身份组成的指纹；实际删除前再次校验路径、Git 跟踪和指纹。路径必须在项目内，不跟随符号链接。变化、占用或权限错误会记录为跳过。

最近结果保存在 `.runtime/storage-maintenance/last-run.json`，包含实际删除项、逻辑字节数、跳过原因和容量提示；自动检查时间在 last-auto.json。结果覆盖保存，不无限追加日志。活动登记正常退出时释放，已退出进程的残留登记在后续维护时清理。
