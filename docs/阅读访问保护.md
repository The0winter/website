# 阅读访问保护

2026-09-28：保护按访问者执行，不把全站总访问量作为正常用户的共同配额。不修改数据库内容、用户账号、现有访问统计或云端防护设置。

## 生效位置与默认规则

- 章节、书籍 HTML，以及 RSC/预取，在 Next proxy 中先调用仅限本机、持有内部凭据的内存检查；直接公开 API 使用同一个 API 进程中的检查器。拒绝发生在数据库准备检查、权限查询和页面生成之前。
- 登录账号以已验签 JWT 的账号 ID 合并额度；匿名浏览器使用服务器签名、HttpOnly、SameSite=Lax 的 7 天 Cookie。这里只用账号标识分组，不替代正常的会话撤销、权限或私有书校验，登录不豁免限流。
- 普通浏览器最多在滚动 2 分钟内读取 120 个不同章节、滚动 1 小时内 600 个不同章节。同一章的页面、API、预取和重试在窗口内只计一次章节；请求本身另有每秒补充 5 次、最多突发 80 次的额度，防止不断刷同一章。冷却返回 429 和 Retry-After，上限 300 秒，届时重试；不永久封禁账号。
- 没有有效 Cookie 的请求按 IP 分组，章节阈值放宽为 2 分钟 480 章、1 小时 2400 章，减少共享出口首次访问的误伤。有各自有效 Cookie 的读者不共用这个 IP 配额。伪造 Cookie 不产生新身份。轮换有效身份和分布式来源仍是边界，不能声称彻底防采集。
- 明确声明 ClaudeBot、GPTBot、CCBot、Bytespider、Diffbot、Omgilibot 的批量采集客户端，书籍/章节读取返回 403；robots.txt 同时声明。Claude-User 等用户触发客户端不在这个名单。其他声明为 bot/spider/crawler 的客户端按来源 IP 降速至每分钟 30 个不同章节、每小时 300 个不同章节；不按自报搜索引擎名称给予无限豁免。UA 可以伪造，通用行为额度仍然适用。
- 图片、字体、静态脚本、评论写入、登录和导入不消耗章节配额，继续使用原本的独立规则。RSC、HEAD、伪造预取头不能免检。

## 调试、观察和运行边界

- `READ_GUARD_MODE` 支持 `off`、`observe`、`enforce`，生产默认 enforce，本地测试/开发默认 off。observe 仍计算本应拒绝的次数，但允许请求通过。
- 原有仅本机且凭据正确的 `x-internal-api-secret` 和本机监控凭据继续可用。外部伪造内部头或来源头不能跳过；nginx 必须覆盖 X-Forwarded-For，网页/API 端口保持只监听 loopback。内部管理接口不能公开代理。
- 大批量线上调试用受控的 SSH 本机通道和现有内部凭据；普通浏览器、无头浏览器和手动操作只要不过量就无需改变。不要把凭据放进网页、URL、截图或报告。
- 目前 API 只有一个进程，HTML 与 API 预算集中于该进程内存；不为每次检查读写 Atlas。最多 5000 个近期身份和 100000 个章节记录，容量不足淘汰旧状态，计数有界。重启会重置额度；扩展多个 API 实例前应迁移到独立共享计数存储，不能让每个实例独立发额度。
- 内部检查不可用时网页返回可重试的 503，不在失联时无限放行抓取。已加载正文继续在浏览器阅读；恢复后可重试，不删除本地阅读进度。
- `/health/metrics` 原有本机凭据保护不变，新增 readGuard 计数及 bookCaches 缓存命中、加载、版本变化、淘汰、失败计数。不记录正文、账号、原始 IP 或 Cookie。

## 降低数据库开销

旧章节文档预检调用整个书籍目录，只为确认一章存在；高频跨书抓取会加载、淘汰并重新构造目录。现在 `/api/books/:bookId/chapter-exists/:chapterId` 优先复用同一数据库、同一书籍版本的现成目录缓存；没有缓存时按章节主键、所属书、未删除条件查询，只返回 exists。这样既不为了存在性检查新建完整目录，也不增加已缓存场景的数据库往返。保留书籍实时权限、归属、下架检查和 HTTP 404；不读取正文。真实打开目录继续使用按书籍版本的共享缓存。

## 验证与回滚

本次验证覆盖正常快速翻页/预取、多读者共享 IP、账号与匿名会话、短时与长时扫描、无/伪造 Cookie、内部凭据伪造、HEAD/RSC、权限及删除/跨书章节、元数据查询预算。历史日志回放只使用服务端日志已有的 IP/UA，无法重建没有记录的 Cookie；该结果不是精确真人误伤率。

发布先在候选目录构建和检查，保留原版本及服务器配置；公网移动端/桌面端验证并屏蔽 GA 上报。故障时切回上一兼容版本；配置可通过 READ_GUARD_MODE=observe 暂停拦截进行调查，不能对线上环境暴露调试豁免。
