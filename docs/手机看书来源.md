# 手机看书网来源

`www.sjks88.com` 使用 `tools/novel-crawler/sites/sjks88.json`，支持输入书籍详情页，例如 `https://www.sjks88.com/chuanyue/52512.html`，并填写完整书名和作者。尚未启用首页搜索。

详情页书名末尾的 `(1-368)` 这类数字范围是收录范围说明，身份核对只移除这一明确后缀；作者只从“作者：”字段提取。目录按网站原有的“第 N 节”顺序读取，排除其他书的链接。网页分节可能跨越原书章界，正文中的原章名与段落保留，不把“下一节”导航混入正文，也不声称一个网页分节就是原书的一章。

2026-09-14 使用独立状态目录验证《我在美国搞内战》的详情查找、作者、完整分节目录和首中尾抽样。该页标注原书 1–368 章，不能据此推断其他书的范围。公开 TXT 按钮的下载链接返回 404，因此当前适配只使用已验证的阅读页，不依赖下载令牌。

采集使用普通 HTTP 请求，默认间隔 1.2 秒、有限重试，浏览器保持无头。后续遇到正文或身份异常仍会停止；本次试采通过不代表该站所有作品完整。实际逐书范围、质量和绑定证据保留在 `.novel-crawler/adapter-checks/sjks88/` 及各采集任务目录，正文与运行数据不提交 Git。
