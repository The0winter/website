# R2 书籍封面

## 使用

进入网站的创作中心，打开作品的「管理」→「书籍信息设置」，点击封面区域选择图片。管理员可以在全站作品列表搜索并管理导入的书籍。

支持 8 MB 以内的 JPG、PNG、WebP，裁剪框固定 3:4。点击「确定」后自动上传并保存；新建作品时，先上传预览，再点击「立即创建」。更换失败时原封面保持不变，移除只解除当前书籍的封面绑定。

Cloudflare 控制台手动上传的图片不会自动关联书籍。通过网站上传才能自动完成压缩、建立归属和保存地址。

## 存储与加载

- `POST /api/upload/cover?purpose=book`：原有会话认证和 CSRF 校验，限制每分钟 10 次、最多同时处理两张图片。
- 浏览器裁剪并缩小至最多 1400 像素宽；服务端验证图片字节、静态格式和 1600 万像素上限，再生成 240 与 480 像素宽的 WebP。原始大图不保存到数据库或 R2。
- 图片写入专用桶 `jiutian-covers` 的 `covers/<唯一媒体ID>/240.webp`、`480.webp`；每次更换使用新 ID。写入后读取并校验 SHA-256，再向客户端返回成功。
- 公共地址以 `https://img.jiutianxiaoshuo.com` 开头，设置 `Cache-Control: public, max-age=31536000, immutable`。列表与详情使用 `srcset` 选择尺寸，重点封面优先加载，其余懒加载；失败时显示占位图。
- MongoDB 的 Media 记录只保留归属、地址、尺寸和校验值。书籍只接受当前用户拥有的完整已登记地址，管理员可为任意书籍上传自己的新封面。旧 MongoDB 封面和头像仍可使用。
- 移除图片会检查所有书籍和头像引用。无引用记录软删除，已上传的 R2 对象暂时保留以便恢复；本功能不启用自动清理，未使用图片可另行审查后清理。

R2 多个桶共享同一账户的免费额度，单独建桶用于隔离封面和章节，不会额外获得一份 R2 免费额度。

## 服务器配置

配置项见 `infra/systemd/api.env.example` 的 `COVER_*`。凭据只授予封面桶的对象读写权限，不复用正文桶凭据，禁止放入 `NEXT_PUBLIC_*` 或 Git。

将真实值保存到 Git 忽略的本地 env 文件，设置 `COVER_STORAGE=r2`，运行：

```powershell
node infra/configure-cover-r2-vps.mjs .runtime/cover-r2.env
```

脚本通过 SSH 标准输入写入 `/etc/test1/api.env`，备份旧配置并保留章节和其他设置，文件权限为 0600；不会打印凭据或重启服务。随已验证的新版本部署后重启 API。Nginx 封面上传位置需要 9 MB 请求上限和 90 秒读取超时，应用仍限制文件为 8 MB。

回滚应保留新增配置和 R2 对象，使用仍支持 R2 封面 URL 的兼容版本；移除数据库数据不属于常规代码回滚。

## 验证

```powershell
node --test server/tests/cover-storage.test.js server/tests/security.test.js
cd web-next
npm run typecheck
npx playwright test covers.spec.ts
```

浏览器测试默认使用合成开发站点 `http://127.0.0.1:3000`，可用 `COVER_TEST_BASE_URL` 指定其他本地端口。它不会操作生产数据库；测试 R2 时需另行在合成开发 API 环境配置专用封面桶。

Cloudflare 参考：[公开桶及缓存](https://developers.cloudflare.com/r2/buckets/public-buckets/)、[免费额度与计费](https://developers.cloudflare.com/r2/pricing/)。
