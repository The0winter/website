# 站点地图与访客观察的 Atlas 出站优化

2026-09-29。保留公开页面、读者目录、阅读记录、上报频率和统计规则，只减少重复查询。原始文档大小、压缩磁盘占用、压缩备份大小与累计出站是不同指标；本次没有降低备份频率，也没有额外下载整库。

## 站点地图

每份章节 XML 仍最多列出 1,000 章，第一页保留书籍详情链接。现在只调用一次 `/api/books/:bookId/sitemap-chapters?page=N`，后端用 `(bookId, chapter_number)` 索引取这一页的 `_id`，不再调用五次普通目录接口，也不为地图加载整本书的阅读索引。读者目录仍返回标题、卷名等原有字段。

每次请求仍检查作品当前的公开/下架状态，私密作品即使由作者本人请求，也不能通过公开地图接口导出。排除已删除章节、保留章号间隙和排序、支持空书和恢复后的章节。后端及内部请求不缓存；XML 原有 `public, max-age=300` 保持，未增加缓存等待时间。数据库故障继续返回可重试 503，不伪装成空目录或 404。

## 访客观察

浏览器每 10 秒及离开页面时的上报不变。服务器缓存最近已成功保存的会话；每次事件仍先写 MongoDB 原始证据，再写评分摘要，完成后才返回成功。没有后台批量刷写或只在内存中确认成功的阶段，缓存淘汰、进程重启不会丢失已经确认的事件。

- 缓存最多 256 个会话，保守估算上限 16 MiB，单条最长 5 分钟；缓存不保存额外身份信息。
- 保存时原子匹配已有 `observationRevision` 与 `lastAt`，其他进程更新后会重新读取、合并当前事件，并有限重试。已有会话更新禁止 upsert，防止过期/删除的数据被缓存复活。
- 同进程的打开、心跳和多标签页更新使用同一会话队列；重复页面 ID 仍去重。旧行无需迁移，首次使用时添加递增版本。
- 摘要写入也校验版本，较慢的旧请求不能覆盖新摘要。失败时丢弃候选缓存并返回失败；证据已写入而摘要失败时，重试仍幂等。
- 关闭 API 时等待在途观察任务，再关闭数据库连接。版本字段为附加字段，可由旧实现读取；部署应排空旧 API 请求，不应长期让旧的无版本写入实现与新版共同接收观察上报。

身份签名、CSRF、30 分钟空闲到期、24 小时会话边界、30 天证据 TTL、评分及访客去重规则保持。观察结果不参与阅读权限、阅读进度或书籍阅读量更新。

## 验证与衡量

同一本地 MongoDB 工作负载：24 章、每章 6 次 10 秒心跳，共 168 次事件。原版与新版最终原始证据和统计摘要逐字段相同（排除随机匿名标识及新增版本字段）。完整会话读取从 190 次降为 1 次，已确认的事件仍有 168 次；未压缩命令回复 BSON 从 571,883 字节降至 11,933 字节，减少 97.9%。这是该受控场景的结果，不是整站 Atlas 账单降幅。

专项验证覆盖多进程并发标签页、重复上报、摘要乱序完成、原始/摘要写入失败、重启恢复、跨天、旧数据、删除、内存限制，以及地图新增/删除/恢复/私密/下架、1,000 章分页和原目录字段。线上验收浏览器在首次导航前屏蔽 GA，并拦截验收流量的阅读计数与访客观察写入。

`/health/metrics` 增加不含身份信息的 `trafficObservation` 计数：完整读取、缓存命中、写入、冲突、失败、缓存条目和估算字节。数据库用途增加 `sitemap`、`traffic`，分别从此前的 `catalog`/`other` 中分离；比较历史用途时须考虑口径变化，不能把分类迁移当成节流收益。

本次详细测试、受控字节对比和部署记录位于 `.runtime/task-artifacts/atlas-query-20260929/`。
