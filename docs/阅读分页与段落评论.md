# 阅读分页与段落评论

阅读正文默认 22px 黑体、1.6 倍行高、暖纸色和首行两字缩进。正常阅读时隐藏导航；点击正文中央，章节名和返回详情按钮下拉显示，同时显示底部工具。导航使用覆盖层，打开时不改变正文高度和分页。时间、电量以及常驻的“上一页 / 菜单 / 下一页”均已移除。页脚仅显示本章页码和按章节进度估算的全书百分比。

手机和桌面设置均提供三种方式，以 `reader_turnMode` 保存，后续章节继续使用：

- **左右翻页**：左右滑动或点击两侧，纸页沿水平方向覆盖翻动。
- **上下滚屏**：原生上下滚动，到章末继续上滑进入下一章；章首下滑返回上一章末尾，鼠标滚轮也能在边界继续切章。
- **上下翻页**：上下滑动或点击上下区域，整页沿竖直方向覆盖翻动。和左右翻页共用 CSS 分栏，避免从文字行中间截断。

覆盖翻页随手指移动，短距离慢拖会回弹，完整滑动或快速划动完成翻页。正文、顶部纸面留白与页脚属于同一张移动纸面。翻动时仅临时复制相邻页作为不可交互、对辅助技术隐藏的视觉层，结束或取消后立即清理；使用 Web Animations API 执行动画，系统启用“减少动态效果”时直接切换。触摸取消、多指缩放和长按不会误触翻页。

分页用实际的小数 CSS 宽度计算栏间距，避免 `clientWidth` 的整数取整误差逐页累积。总页数容忍 `scrollWidth` 小于 1px 的取整误差，不把末尾舍入误差算成空白页。段落允许仅一行跨页，按字形及行高消除页底不可见的半行间距，同时收紧纸面上下留白。最后一页不足一页属于正常章节长度，不添加“本章完 / 下一章”过渡页。

首次访问仍使用服务端生成的正文。书内切章改为保留阅读器、切换已解析的章节数据，并通过 Next 支持的原生 History API 更新 URL；刷新、浏览器前进后退仍指向相应章节。正文缓存最多 20 章且约 6 MiB（单个超大章节可保留），相邻章节仅保留前后各一份排版预览。正常网络下同时预加载前后章节及段评数量；离线、后台和省流策略继续生效。预览不挂载阅读组件，不触发阅读量或书架操作。

到本章末页后，下一次翻页直接露出下一章首页；反向翻回上一章末页。已准备的章节不再等待页面路由或重新下载正文。未缓存或请求失败时保留当前正文，提示加载或重试；离开阅读器会取消待完成的导航，避免慢请求把用户拉回旧页面。

方向键或 PageUp/PageDown 翻页；Ctrl+左右方向键从章首切换章节。M 打开菜单，Escape 收起；键盘和读屏还有可聚焦的“阅读菜单”入口。原有目录、字体主题设置、书架和预加载缓存继续使用。刷新恢复阅读位置；滚屏保存页内偏移，字号、视口或阅读模式变化后按章节位置重新排版。无脚本样式将分栏和覆盖层降为连续正文。

长按正文 450ms，或右键、聚焦段落后按 Enter/Shift+F10，打开评论与标记菜单。移动端松手产生的合成点击不会立即关闭菜单。背景标记按当前浏览器、账户及章节保存；可再次长按取消，不同步到其他设备。

公开段评存储于 `ParagraphComment` 集合，通过已登录会话及 CSRF 校验发布。正文与段落键由客户端、服务端共用的解析器生成，插入其他不同段落不会改变原段落键；相同文字的重复段落使用出现序号区分。段落被改写后旧评论不会附到新文字上。发布使用请求编号防止网络重试生成重复评论，正文限制 1000 字，分页每页 20 条。只有评论作者或管理员能删除。气泡在评论数大于 10 时变红。

上线准备从当前兼容版本复制，仅覆盖本次前端文件并核对哈希，保留回滚版本。此次翻页优化不涉及数据库和 API 变更，现有段评索引继续使用。

## 验证

- 本地 MongoDB 的段评测试 7 项、安全回归 18 项通过。
- 浏览器验证 320、390、768、1440 宽度、真实触摸长按与滑动、标记重载、评论发布与删除、10/11 条颜色切换、纯文本呈现、长段落跨页、横竖屏及退出阅读后恢复滚动。
- 原有缓存边界测试通过：34 个章节、5 本书；连续 100 次章节切换与返回测试通过。
- 新增真实触屏回归：隐藏导航及不挤动正文、跟手位移、慢拖回弹、触摸取消、上下翻页、三种模式保存、滚屏精确恢复和上下滑动跨章。
- 新增 320/390/413 宽度、2.75 倍像素比和小数布局的逐页检查：无左右裁字、底部裁字或空白末页；覆盖 22/26px 字号。
- 左右及上下跨章的真实触屏检查通过；已缓存前后切章不产生章节 API 或 RSC 请求，顶部纸面与正文一起移动。请求失败后的重试、离开页面后慢请求不抢回导航通过。
- TypeScript 和相关 ESLint 通过。
- 旧回归中“完全禁用 JavaScript 后可见正文”和“缺失章节 HTTP 404”仍受现有 Next 流式加载影响。当前线上旧版同样可复现：无脚本详情隐藏、缺失章节返回流式 200。此次未改动全站流式加载策略；无脚本样式仅保证正文已呈现时不被分页裁切。

实现参考：[Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)、[开源阅读器对覆盖与滚动翻页的分类](https://github.com/Peyilo/libreadview)。采用文字保持平直的覆盖动效，未引入位图截图或第三方翻页库。
