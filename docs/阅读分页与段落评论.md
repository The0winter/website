# 阅读分页与段落评论

阅读正文使用按视口高度排版的 CSS 分栏，默认 22px 黑体、1.6 倍行高、暖纸色和首行两字缩进。第一页顶栏为书名，后续页为章节名；顶栏包含返回详情、时间，以及浏览器支持时的真实电量。页脚显示本章页码和按章节进度估算的全书百分比。

点击正文两侧、左右滑动、方向键或 PageUp/PageDown 翻页；点击中间或页脚菜单打开阅读工具。Ctrl+左右方向键切换章节。原有目录、字体主题设置、书架和预加载缓存继续使用。刷新恢复页内进度，字号或视口变化后重新分页。无脚本样式将分栏降为连续正文。

长按正文 450ms，或右键、聚焦段落后按 Enter/Shift+F10，打开评论与标记菜单。移动端松手产生的合成点击不会立即关闭菜单。背景标记按当前浏览器、账户及章节保存；可再次长按取消，不同步到其他设备。

公开段评存储于 `ParagraphComment` 集合，通过已登录会话及 CSRF 校验发布。正文与段落键由客户端、服务端共用的解析器生成，插入其他不同段落不会改变原段落键；相同文字的重复段落使用出现序号区分。段落被改写后旧评论不会附到新文字上。发布使用请求编号防止网络重试生成重复评论，正文限制 1000 字，分页每页 20 条。只有评论作者或管理员能删除。气泡在评论数大于 10 时变红。

上线准备会从当前兼容版本复制，仅覆盖本次文件并核对哈希；为新评论集合建立普通索引和请求去重唯一索引。现有正文、R2 引用、账户及服务配置不修改。

## 验证

- 本地 MongoDB 的段评测试 7 项、安全回归 18 项通过。
- 浏览器验证 320、390、768、1440 宽度、真实触摸长按与滑动、标记重载、评论发布与删除、10/11 条颜色切换、纯文本呈现、长段落跨页、横竖屏及退出阅读后恢复滚动。
- 原有缓存边界测试通过：34 个章节、5 本书；连续 100 次章节切换与返回测试通过。
- TypeScript 和相关 ESLint 通过；ReaderClient 保留已有的数据加载 effect 依赖警告。
- 旧回归中“完全禁用 JavaScript 后可见正文”和“缺失章节 HTTP 404”仍受现有 Next 流式加载影响。当前线上旧版同样可复现：无脚本详情隐藏、缺失章节返回流式 200。此次未改动全站流式加载策略；无脚本样式仅保证正文已呈现时不被分页裁切。

电量按浏览器能力检测，无法读取时不显示虚构电量。参见 [Battery Status API](https://developer.mozilla.org/en-US/docs/Web/API/Battery_Status_API)。
