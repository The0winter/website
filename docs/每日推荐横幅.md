# 每日精选横幅

移动端精选页横幅展示三本书，每 6 秒自动滚动，可左右滑动、点击圆点切换或暂停。横幅不在视口、页面在后台、键盘焦点位于横幅或用户选择减少动态效果时不自动播放。横幅手势不触发精选、书架、交流区之间的切换。

候选池按公开在架作品的总浏览量降序、书籍 ID 升序确定，为第 50–100 名（包含边界）。每天优先排除上次推荐的三本书，以当天北京时间日期和书籍 ID 生成稳定随机分，随机占 80%、综合评分占 20%，依次选择时对重复作者和题材扣分。候选不足三本的小书库使用现有公开作品，不重复凑数。

现有 `test1-daily-popularity.timer` 在每日基础热度生成完成后保存 `DailyFeatured` 记录，包含日期、算法版本、书籍 ID 和选取时的浏览排名。同一天的书单不随新增浏览或服务重启变化；每日检查不会重复抽签。生成新书单之前沿用前一次书单，刚安装尚无记录时使用只读计算结果。接口始终重新过滤已隐藏或删除的书籍。

API：`/api/books?orderBy=featured_daily&limit=3`。桌面首页保留原有横幅布局和热门推荐；移动端下方的 56 本推荐与这三本书去重。算法集中在 `server/services/daily-featured.js`，可后续调整。
